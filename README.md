# Active Directory Groups & Group Policy Lab

## Overview
Hands-on Windows Server Active Directory lab focused on security groups, user membership, Organizational Units (OUs), and Group Policy.

## Objectives
- Create department security groups
- Add users to appropriate groups
- Create and link department GPOs
- Configure desktop background policy
- Apply and verify policies on Windows 10 clients

## Departments
- HR
- IT
- Management
- Operations

## Tools
- Windows Server 2022
- Active Directory Users and Computers
- Group Policy Management
- Windows 10
- VMware Workstation

## Skills Practiced
- Active Directory user and group management
- Security group membership
- Organizational Units
- Group Policy creation and linking
- GPO configuration
- `gpupdate /force`
- Policy verification and troubleshooting
